# tests/

Тесты для проекта.

## Структура

### bot/
Тесты для Telegram бота.

**Планируемые тесты:**
- Тестирование обработчиков команд
- Проверка валидации данных
- Тесты интеграции с БД
- Мок-тесты Telegram API

### workflows/
Тесты для N8N workflows.

**Планируемые тесты:**
- Тестирование логики workflows
- Проверка SQL запросов
- Тесты форматирования сообщений
- Интеграционные тесты

## Фреймворки

Рекомендуемые инструменты:
- **Jest** - для Node.js тестов бота
- **Supertest** - для API тестов
- **N8N testing** - встроенные инструменты N8N

## Запуск тестов

```bash
# Тесты бота
cd src/bot
npm test

# Тесты с покрытием
npm run test:coverage

# Watch режим для разработки
npm run test:watch
```

## Требования

- Node.js 18+
- Запущенная тестовая БД PostgreSQL
- Моки для внешних API (Telegram)

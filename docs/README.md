# docs/

Документация проекта.

## Структура

### deployment/
Инструкции по развертыванию.

**Файлы:**
- `beget-setup.md` - Полная инструкция по развертыванию на Beget VPS
- `bot-setup.md` - Настройка и запуск Telegram бота

**Основные шаги:**
1. Настройка VPS
2. Установка Docker
3. Конфигурация сервисов
4. Настройка SSL
5. Импорт workflows

### workflows/
Документация по N8N workflows.

**Файлы:**
- `README.md` - Описание всех workflows
- `AUDIT_REPORT.md` - Отчет о проверке и исправлении workflows

**Workflows:**
1. **telegram-bot-main** - Обработка команд /start, /services, /help
2. **notifications** - Напоминания за день до записи (ежедневно в 10:00)
3. **admin-stats** - Статистика для админа (ежедневно в 20:00)

### architecture/
Архитектурная документация.

**Содержание:**
- Диаграммы системы
- Описание компонентов
- Потоки данных
- API документация

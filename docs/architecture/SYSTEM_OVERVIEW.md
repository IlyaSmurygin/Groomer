# Архитектура системы Grooming Salon

## Обзор

Grooming Salon - это система управления записями клиентов груминг-салона, построенная на базе Telegram бота и N8N для автоматизации бизнес-процессов.

## Компоненты системы

### 1. Telegram Bot
**Назначение:** Интерфейс взаимодействия с клиентами

**Технологии:**
- Node.js 18+
- Grammy framework
- PostgreSQL клиент (pg)

**Основные функции:**
- Регистрация новых клиентов
- Добавление информации о питомцах
- Просмотр доступных услуг
- Запись на процедуры
- Управление записями

### 2. N8N Workflows
**Назначение:** Автоматизация бизнес-процессов

**Workflows:**

#### telegram-bot-main
- Обработка входящих команд
- Маршрутизация запросов
- Регистрация новых пользователей
- Отправка информационных сообщений

#### notifications
- Автоматическая отправка напоминаний
- Запуск: ежедневно в 10:00
- Напоминания за день до записи
- Обновление статуса reminder_sent

#### admin-stats
- Сбор статистики
- Запуск: ежедневно в 20:00
- Общая статистика по записям
- Список записей на завтра
- Отправка отчета администратору

### 3. PostgreSQL Database
**Назначение:** Хранение всех данных системы

**Схема:**
- **clients** - Информация о клиентах
- **pets** - Данные о питомцах
- **services** - Каталог услуг салона
- **appointments** - Записи на процедуры

**Ключевые особенности:**
- Внешние ключи для целостности данных
- Индексы для быстрого поиска
- Проверочные ограничения (CHECK)
- Значения по умолчанию

### 4. Вспомогательные сервисы

#### Redis
- Кэширование данных
- Сессии пользователей
- Очереди задач

#### pgAdmin
- Веб-интерфейс для управления БД
- Доступ: http://localhost:5050

## Потоки данных

### Регистрация нового клиента
```
Пользователь → /start → Telegram Bot API → N8N (telegram-bot-main)
                                              ↓
                                    Проверка пользователя в БД
                                              ↓
                                    Создание записи в clients
                                              ↓
                                    Отправка приветственного сообщения
```

### Создание записи на процедуру
```
Клиент → /book → N8N
                  ↓
         Получение списка питомцев
                  ↓
         Выбор питомца
                  ↓
         Получение списка услуг
                  ↓
         Выбор услуги
                  ↓
         Выбор даты и времени
                  ↓
         Создание записи в appointments
                  ↓
         Подтверждение клиенту
```

### Отправка напоминаний
```
Cron (10:00) → N8N (notifications)
                      ↓
              Выборка завтрашних записей
                      ↓
              Для каждой записи:
                      ↓
              Форматирование сообщения
                      ↓
              Отправка через Telegram
                      ↓
              Обновление reminder_sent = true
```

## Безопасность

### Аутентификация
- Telegram ID как уникальный идентификатор
- N8N защищен Basic Auth
- PostgreSQL с паролем

### Защита данных
- Все пароли в переменных окружения
- .env не коммитится в git
- SSL для внешнего доступа (Nginx)

### Бэкапы
- Автоматическое резервное копирование БД
- Хранение бэкапов 30 дней
- Скрипты восстановления

## Масштабируемость

### Горизонтальное масштабирование
- N8N поддерживает кластеризацию
- PostgreSQL можно реплицировать
- Redis для распределенных сессий

### Вертикальное масштабирование
- Увеличение ресурсов контейнеров
- Оптимизация индексов БД
- Кэширование частых запросов

## Мониторинг

### Логи
- Docker logs для всех сервисов
- N8N встроенное логирование
- Rotation логов (7 дней)

### Метрики
- Количество запросов
- Время ответа
- Ошибки и исключения
- Статистика использования

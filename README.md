# 🐾 Груминг Салон - Telegram Бот для записи клиентов

Автоматизированная система записи клиентов в груминг салон через Telegram бота с использованием N8N в качестве оркестратора.

## 🏗 Архитектура

```
┌─────────────────┐
│  Telegram Bot   │  ← Точка входа для клиентов
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│      N8N        │  ← Оркестратор workflow
│   (Workflows)   │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│  PostgreSQL/    │  ← База данных
│    SQLite       │
└─────────────────┘
```

### Компоненты системы:

1. **Telegram Bot** - интерфейс взаимодействия с клиентами
2. **N8N** - автоматизация бизнес-процессов
3. **База данных** - хранение данных (клиенты, питомцы, записи)
4. **Webhook сервер** - обработка запросов от Telegram
5. **Beget** - облачный хостинг для развертывания

## 🚀 Быстрый старт

### Предварительные требования

- Docker и Docker Compose
- Telegram Bot Token (от @BotFather)
- Аккаунт на Beget (для продакшена)

### Локальная разработка

1. **Клонируйте репозиторий**
```bash
git clone <repo-url>
cd Groomer
```

2. **Настройте переменные окружения**
```bash
cp .env.example .env
# Отредактируйте .env и добавьте:
# TELEGRAM_BOT_TOKEN=your_token
# N8N_ENCRYPTION_KEY=your_key
# DATABASE_URL=postgresql://user:password@db:5432/grooming
```

3. **Запустите через Docker Compose**
```bash
docker-compose up -d
```

4. **Откройте N8N**
```
http://localhost:5678
```

5. **Импортируйте workflows**
- Откройте N8N в браузере
- Импортируйте файлы из папки `n8n/workflows/`

## 🔧 N8N Workflows

### 1. Telegram Bot Handler (telegram-bot.json)
Основной workflow для обработки сообщений от пользователей:
- Получение команд
- Валидация пользователей
- Маршрутизация к нужным обработчикам
- Отправка ответов

### 2. Appointments Manager (appointments.json)
Управление записями:
- Создание новых записей
- Проверка доступности времени
- Обновление статусов
- Отмена записей

### 3. Notifications (notifications.json)
Система уведомлений:
- Напоминания о записях (за 24 часа)
- Подтверждения записей
- Уведомления об изменениях

## 🌐 Развертывание на Beget

### Шаг 1: Подготовка

1. Закажите VPS на Beget
2. Подключитесь по SSH
3. Установите Docker и Docker Compose

### Шаг 2: Настройка базы данных

```bash
# Создайте базу PostgreSQL через панель Beget
# Или используйте SQLite для простоты
```

### Шаг 3: Загрузка проекта

```bash
git clone <repo-url>
cd Groomer
```

### Шаг 4: Конфигурация

```bash
# Настройте .env файл
nano .env

# Примените миграции БД
docker-compose exec db psql -U user -d grooming -f /database/schema.sql
```

### Шаг 5: Запуск

```bash
docker-compose -f docker-compose.prod.yml up -d
```

### Шаг 6: Настройка Nginx

```bash
# Скопируйте конфиг nginx
sudo cp deploy/nginx.conf /etc/nginx/sites-available/grooming
sudo ln -s /etc/nginx/sites-available/grooming /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

### Шаг 7: SSL сертификат

```bash
sudo certbot --nginx -d yourdomain.com
```

Подробные инструкции в `deploy/beget-setup.md`

## 🎯 Workflow процесс записи

1. Клиент отправляет `/book` в Telegram
2. Бот запрашивает выбор питомца
3. Бот показывает доступные услуги
4. Клиент выбирает дату
5. Бот показывает свободные слоты
6. Клиент выбирает время
7. N8N проверяет доступность
8. Создается запись в БД
9. Клиент получает подтверждение
10. За 24 часа отправляется напоминание

# 🐾 Груминг Салон - Система управления записями

Веб-приложение для груминг салона, позволяющее управлять записями клиентов на процедуры для их питомцев.

## 📋 Возможности

### Управление клиентами
- ✅ Регистрация новых клиентов с контактной информацией
- ✅ Просмотр списка всех клиентов
- ✅ Хранение телефона и email

### Управление питомцами
- ✅ Регистрация питомцев с привязкой к владельцу
- ✅ Указание типа животного (собака, кошка, другое)
- ✅ Информация о породе и размере
- ✅ Дополнительные заметки о питомце

### Каталог услуг
- ✅ Полный список услуг груминга
- ✅ Стрижка, мытье и сушка, тримминг
- ✅ Стрижка когтей, чистка ушей
- ✅ Комплексный уход и SPA процедуры
- ✅ Экспресс линька
- ✅ Указание длительности и стоимости каждой услуги

### Система записи
- ✅ Создание записей на процедуры
- ✅ Выбор даты и времени
- ✅ Проверка доступности временных слотов
- ✅ Рабочие часы: 9:00 - 19:00 (слоты по 30 минут)

### Календарь записей
- ✅ Просмотр предстоящих записей
- ✅ История выполненных процедур
- ✅ Управление статусами (запланировано, выполнено, отменено)
- ✅ Редактирование и удаление записей

### Статистика
- ✅ Общее количество клиентов
- ✅ Количество зарегистрированных питомцев
- ✅ Предстоящие записи
- ✅ Выполненные процедуры

## 🚀 Установка и запуск

### Требования
- Node.js версии 16 или выше
- npm или yarn

### Установка зависимостей

```bash
npm install
```

### Запуск в режиме разработки

```bash
npm run dev
```

Приложение откроется по адресу: `http://localhost:5173`

### Сборка для продакшена

```bash
npm run build
```

Собранные файлы будут в папке `dist/`

### Предварительный просмотр продакшен версии

```bash
npm run preview
```

## 📝 Использование

### 1. Регистрация клиента
1. Перейдите на вкладку "Клиенты и питомцы"
2. Заполните форму "Регистрация клиента":
   - Введите имя клиента (обязательно)
   - Введите телефон (обязательно)
   - Опционально: email
3. Нажмите "Добавить клиента"

### 2. Регистрация питомца
1. На той же вкладке "Клиенты и питомцы"
2. Заполните форму "Регистрация питомца":
   - Выберите владельца из списка
   - Введите кличку питомца
   - Выберите тип животного (собака/кошка/другое)
   - Укажите породу
   - Выберите размер
   - Добавьте примечания (опционально)
3. Нажмите "Добавить питомца"

### 3. Запись на процедуру
1. Перейдите на вкладку "Записи"
2. Заполните форму записи:
   - Выберите клиента
   - Выберите питомца (появятся только питомцы выбранного клиента)
   - Выберите услугу
   - Выберите дату
   - Выберите свободное время (занятые слоты будут недоступны)
   - Добавьте примечания (опционально)
3. Нажмите "Записать"

### 4. Управление записями
В календаре записей вы можете:
- Просмотреть все предстоящие записи
- Отметить процедуру как выполненную
- Отменить запись
- Удалить запись
- Просмотреть историю всех записей

### 5. Просмотр услуг
На вкладке "Услуги" отображается полный каталог доступных процедур с:
- Описанием услуги
- Длительностью выполнения
- Стоимостью
- Типами животных, для которых доступна услуга

## 💾 Хранение данных

Приложение использует LocalStorage браузера для хранения данных:
- `grooming_clients` - список клиентов
- `grooming_pets` - список питомцев
- `grooming_appointments` - список записей

**Важно:** Данные хранятся локально в браузере. При очистке кэша браузера данные будут удалены.

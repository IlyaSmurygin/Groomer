# scripts/

Вспомогательные скрипты для управления проектом.

## Структура

### setup/
Скрипты для первоначальной настройки.

**init-project.sh** - Инициализация проекта
```bash
./setup/init-project.sh
```
Выполняет:
- Проверку установки Docker
- Создание .env из .env.example
- Создание директорий для данных
- Установку прав доступа
- Установку зависимостей бота

### backup/
Скрипты резервного копирования.

**backup-database.sh** - Создание резервной копии БД
```bash
./backup/backup-database.sh
```
- Создает сжатый дамп PostgreSQL
- Сохраняет в `backups/` с меткой времени
- Автоматически удаляет бэкапы старше 30 дней

**restore-database.sh** - Восстановление из резервной копии
```bash
./backup/restore-database.sh backups/grooming_salon_backup_20250101_120000.sql.gz
```
⚠️ ВНИМАНИЕ: Перезаписывает текущую БД!

### maintenance/
Скрипты обслуживания.

**cleanup.sh** - Очистка проекта
```bash
./maintenance/cleanup.sh
```
Выполняет:
- Удаление старых логов (>7 дней)
- Удаление временных файлов
- Очистка кэша npm
- Очистка Docker (опционально)

## Установка прав

Перед использованием дайте права на выполнение:
```bash
chmod +x scripts/**/*.sh
```

Или используйте init-project.sh для автоматической установки прав.
